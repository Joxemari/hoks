Regla

El fondo llega siempre al canto: fillRect(0,0,W,H). Ninguna obra tiene margen blanco — 25 obras guardadas, 150 puntos de borde muestreados, cero píxeles blancos. El margen interno es de los elementos, no del fondo: esa banda es color de paleta, no papel. Y no es el 11 % — ese es solo el objetivo con el que se elige k. En DIN el margen está cuantizado (8,58 % toda n par; 13,76 / 15,48 / 18,93 / 29,29 % las impares) y PLLS no tiene ninguno. Nunca el «sin bordes» del driver — escala la imagen y recorta.
